# gaonjh.com

가온제이에이치(GAONJH)의 한 페이지 홈페이지입니다. GitHub Pages로 게시합니다. 고객사 이름과 고객 포트폴리오는 공개하지 않습니다.

- `index.html`과 `style.css`에는 캠페인 표지, 개발 이력, B팀의 역할과 제작 범위, 구간별 계약, 문의처가 있습니다.
- 표지와 본문의 휴머노이드는 이 홈페이지를 위해 만든 개념 이미지입니다. `assets/humanoid.webp`는 표지용 이미지이고, `assets/robot-detail.webp`는 같은 디자인의 목과 어깨, `assets/hand-detail.webp`는 제작 범위에서 보여 주는 손가락·손목 접사입니다.
- `assembly.js`는 큰 화면의 기본 모션 설정에서만 스크롤에 맞춰 로봇의 점 6,400개를 표지 하단 B–TEAM 윤곽으로 옮기고 획을 채웁니다. 시작 좌표와 재질색은 `assets/point-map.js`에 있습니다. 작은 화면과 동작 줄이기 설정에서는 정적 표지를 봅니다.
- 글꼴은 페이지용으로 추린 Pretendard, Archivo Black, IBM Plex Mono입니다. 각 이용 조건은 `assets/OFL.txt`, `assets/Archivo-OFL.txt`, `assets/Plex-OFL.txt`에 있습니다.
- 로컬 검토 자료는 `_review/`에 있습니다.
