# gaonjh.com

가온제이에이치(GAONJH) 홈페이지 원본입니다. GitHub Pages로 게시합니다. 고객사 이름은 쓰지 않습니다(비밀 유지).

- `index.html`과 `style.css`에 회사 소개, 진행 방식, 연혁, 문의처가 있습니다. `favicon.svg`는 회사 표식입니다.
- 첫 화면은 `assets/robot-arm.webp`의 로봇 팔 설계 개념도를 표시합니다. `assembly.js`는 `assets/point-map.js`에 담긴 도해의 점을 ‘B팀’의 글자 획으로 옮깁니다. 동작 줄이기를 쓰면 스크롤에 따른 모양 전환을 끕니다.
- `assets/gaon-*.woff2`는 이 페이지에서 쓰는 글자를 추려 다시 이름 붙인 Pretendard 글꼴입니다. 이용 조건은 `assets/OFL.txt`에 있습니다.
- `_review/`에 로컬 검토용 캡처와 협의 기록을 둡니다.
